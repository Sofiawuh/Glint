# Glint 智能翻译与 Azure Speech 实施计划

日期：2026-11-24  
状态：已完成

## 1. 配置与协议契约

1. 由独立测试代理先建立以下黑盒契约并确认红灯：
   - 翻译目标与排版设置的默认值、迁移和持久化；
   - 智能排版区块、硬换行修复、结构保护和严格保留；
   - Translator 多片段请求、响应重组和语言检测；
   - Speech 请求、SSML 转义、语音映射和错误脱敏；
   - 排版后纯文本 / RTF 复制模型；
   - 翻译工作台状态、重译代际、编辑内容与历史更新。
2. 扩展 `AppConfig`，向后兼容已有配置。
3. 实现 Translator 文档请求与 Azure Speech REST 适配。

## 2. 智能排版领域层

1. 新增独立的纯 Swift 格式化模型与区块解析器。
2. 实现智能模式与严格保留模式。
3. 实现按结构拆分、批量预算、不可变 token 保护和稳定重组。
4. 实现原文 / 译文富文本展示与剪贴板表示。

## 3. 设置与工作台

1. 基础页增加目标语言与排版模式，并在选择后独立事务保存、失败回滚。
2. Azure 页增加 Speech Endpoint、Key、声音和连接探测。
3. 将单译文窗口替换为双编辑区翻译工作台。
4. 接入重新翻译、双复制、复制全部、双朗读与停止。
5. 更新最近结果的翻译快照与同记录更新逻辑。
