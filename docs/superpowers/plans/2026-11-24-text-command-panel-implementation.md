# Glint 文字命令面板实施计划

日期：2026-11-24
对应设计：[2026-11-24-text-command-panel-design.md](../specs/2026-11-24-text-command-panel-design.md)

## 阶段 1：测试契约

由全新上下文的独立测试代理先添加黑盒测试，覆盖：

- 新文字快捷键默认值、显示文本和 Codable 迁移；
- 缺失新字段时保留 Azure 配置与截图快捷键；
- 两套快捷键冲突拒绝；
- 注册、保存或旧键注销失败时保留旧有效键；
- 录制期间按当前快捷键只回填录制器；
- AX 文本优先、复制降级、空白和非文本对象拒绝；
- 剪贴板完整恢复和第三方竞争更新保护；
- 鼠标附近布局、四边夹紧与负坐标显示器；
- 面板直接双按钮、重复请求替换、外部点击和 Escape 关闭；
- 鼠标释放、移动、双击及普通键盘选择不再自动显示入口；
- 截图快捷键和现有 Azure 流程回归。

主代理运行新增测试并确认其因缺少新能力而准确失败，记录红灯输出后才修改生产代码。

## 阶段 2：领域实现

1. 将快捷键值类型抽象为可复用模型或新增文字快捷键模型，保持旧配置兼容。
2. 扩展 Carbon 注册与事务切换，使截图和文字命令拥有不同 ID、独立录制路由与冲突校验。
3. 为 `AppConfig` 增加文字命令快捷键字段和安全持久化方法。
4. 从现有选区代码中提取按需取词能力：AX 非空文本优先，受保护复制降级，拒绝非文本对象并保护剪贴板代次。
5. 新增纯状态/几何层，描述请求代际、显示状态、替换、关闭和鼠标附近夹紧布局。

## 阶段 3：UI 与主控接线

1. 新增 non-activating 文字命令面板，直接呈现“翻译”“提问”。
2. 新增无文本短暂提示，并共享鼠标附近的屏幕夹紧定位。
3. `AppDelegate` 注册默认 `⌃⌥T`，连接取词、面板与现有翻译/提问动作。
4. 设置基础页增加独立文字快捷键录制器、帮助文案和错误状态。
5. 删除主控中的自动选区观察、marker hover 与 mouseMoved 入口链路；仅保留仍被其他能力使用的事件 Tap 行为。
6. 从构建清单清理不再使用的旧入口源码与测试，避免保留死代码。

## 阶段 4：文档与迁移

1. 更新 `PROJECTS.md`、`docs/architecture/overview.md`、README 和 CHANGELOG 中的当前能力描述。
2. 新增 ADR 记录“显式快捷键取代自动选区悬停入口”，并将旧的选区角点定位 ADR 标记为被取代后归档。
3. 保留历史规格和计划，不改写历史结论；在新文档中声明 supersede 关系。

## 阶段 5：验证与上线

1. 运行新测试、现有完整 Swift 测试和静态契约检查。
2. 对 `arm64` 与 `x86_64` 执行类型检查或等价编译验证。
3. 使用固定身份 `Glint Self Signed` 构建 Universal Binary、App 和 DMG。
4. 将现有 `/Applications/Glint.app` 移入带时间/随机后缀的 `/tmp` 备份目录，再复制新版本并重启。
5. 验证安装版签名、双架构、进程、菜单栏 UI、设置页两套快捷键和命令面板核心流程。
6. 由独立只读复审代理审查差异和测试结果；只有 `APPROVE / P0=0 / P1=0 / P2=0` 才提交。

## 阶段 6：GitHub 交付

1. 提交功能分支并推送 `origin`。
2. 创建 PR，核对 PR diff 与检查结果，并将 PR 附加到当前任务。
3. 使用 merge commit 合并到 `main`，不 squash、不 rebase、不删除功能分支。
4. 本地切回 `main` 并 fast-forward 到远端最终 SHA。
5. 更新 Obsidian 项目事实、增量文件清单与任务日志。
