# ADR-0004: 显式文字命令快捷键取代自动选区悬停入口

- **状态 (Status)**：Accepted
- **日期 (Date)**：2026-11-24
- **取代 (Supersedes)**：[ADR-0001](superseded/0001-cursor-bottom-right-placement.md) 中的自动选区入口与释放点触发决策

## 1. 背景与上下文

Glint 曾尝试通过全局鼠标/键盘事件、Accessibility 选区范围、鼠标命中元素、父级角色链和受保护复制，自动判断用户是否真正选中了正文，再在选区右下角显示小方块并等待悬停展开。

实测表明，Safari、微信、VS Code、Excel、Electron、自绘文本控件和多行选区返回的 AX 文本、范围与 bounds 并不一致；滚动区域、Dock 项和其他控件也可能提供可复制文本。自动入口因此同时存在漏触发、错位和误触，而且 hover 生命周期又增加了“入口已出现但永远不展开”的状态。

## 2. 决策

1. 新增独立的全局文字命令快捷键，默认 `⌃⌥T`，与截图快捷键分别录制且不得重复。
2. 只有用户主动按下文字命令快捷键才读取选中文字；普通拖选、双击、键盘扩选、`⌘A`、滚动和调整窗口不触发读取或入口。
3. 取词优先读取当前焦点元素及有限父链的非空 `AXSelectedText`；无文本时执行完整备份/安全恢复剪贴板的受保护 `⌘C`。
4. 读取成功后在当前鼠标右下约 12 pt 直接显示“翻译｜提问”，不再使用 marker、透明命中区、选区 bounds 或 hover 阶段。
5. 面板为 non-activating `NSPanel`，外部点击或 Escape 关闭；新快捷键请求替换旧快照，晚到结果通过代际令牌淘汰。
6. 保留现有 Azure Translator、Azure OpenAI v1、截图、提问卡片、流式会话和结果窗，不改变其协议。

## 3. 后果

### 正面

- 触发意图明确，不再猜测拖选、滚动、双击或控件角色。
- 不依赖跨应用不一致的选区 bounds，面板位置只取决于鼠标和显示器 `visibleFrame`。
- 去除 marker/hover 状态机、mouseMoved 监听与大量跨应用分支，运行链路更短且可测试。
- 受保护复制只在用户明确触发后发生，降低意外剪贴板操作与误弹概率。

### 代价

- 用户需要多按一次快捷键，无法再做到自动出现入口。
- 不能提供选区右下角的精确视觉附着；命令面板固定跟随当前鼠标位置。
- 辅助功能权限不足时会更多依赖复制降级；AX 与复制都不可用时只能提示先选中文字。

## 4. 不变量

- 两套快捷键冲突、注册失败、保存失败或旧键注销失败时，旧有效键必须继续工作。
- 剪贴板仅在仍属于本事务的复制代次时恢复；外部竞争更新不得被覆盖。
- 文件、图片、文件 URL、空白与非文本对象不得进入翻译或提问流程。
- 日志不得记录真实选中文字、剪贴板正文或 Azure 凭据。
